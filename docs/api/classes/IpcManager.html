Class IpcManager

IpcManager class for managing multiple handlers

Example

const ipc = new IpcManager(ipcMain);

ipc.handle('my-addon:get-data', async (req) => {
  return { success: true, data: await getData(req.id) };
});

ipc.handleSimple('my-addon:ping', async () => ({
  timestamp: Date.now()
}));
